# Setup Solar Files (RUST)
This repository is mainly used for setting up your `.solar-file` for your Solar Engine mod/script. We have two different version that is being worked on!

This version offers the CLI, hovering under below <200 kb with the help of [Cargo's features](Cargo.toml).

## Why pick this over the [GUI](https://github.com/Team-SolarEngine/setup-solarfiles/tree/haxe)?
It's lighter, and way faster for something simple. I mean, CLI over GUI is kinda obvious because of the absurd file size.

Also, because the CLI tool has more platforms to use rather than *windows only*

## Where to download?
- Linux X86_64; [setup-solarfiles-Linux](https://nightly.link/Team-SolarEngine/setup-solarfiles/workflows/build.yaml/rust/setup-solarfiles-Linux.zip)
- Windows x86_64; [setup-solarfiles-Windows](https://nightly.link/Team-SolarEngine/setup-solarfiles/workflows/build.yaml/rust/setup-solarfiles-Windows.zip)
- M1-M5 Macbook Chips; [setup-solarfiles-macOS-Arm64](https://nightly.link/Team-SolarEngine/setup-solarfiles/workflows/build.yaml/rust/setup-solarfiles-macOS-Arm64.zip)
- Intel Chips; [setup-solarfiles-macOS-Intel](https://nightly.link/Team-SolarEngine/setup-solarfiles/workflows/build.yaml/rust/setup-solarfiles-macOS-Intel.zip)
